# Технический стек

**Собирать нечего — коммит становится сайтом.** Это не следствие лени, а
принятое требование: у дашборда нет шага сборки, и поэтому нет ни состояния
«собралось локально, но не в CI», ни устаревшего артефакта, ни зависимости,
которая сломается через год.

## Из чего сделано

| Слой | Чем | Чего намеренно нет |
|---|---|---|
| Страницы | статический HTML, ES-модули, CSS | бандлера, фреймворка, шага сборки |
| Стили | CSS custom properties, `data-theme` | препроцессора, Tailwind |
| Графики | свой SVG-модуль `charts.js` | Chart.js, D3, Recharts |
| Markdown вики | свой разбор `markdown.js` | marked, markdown-it |
| Языки | свой словарь, ru / en / uk | i18next |
| Вход | PBKDF2-SHA256, 150 000 итераций, WebCrypto | сервера, сессий, БД |
| Данные | статические JSON в `data/`, читаются `fetch` | API, бэкенда |
| Сборщики | Python 3.12, **только стандартная библиотека** | requests, boto3, pandas |
| Клиент SP-API | свой, LWA-токен в заголовке | AWS SigV4, SDK Amazon |
| Хостинг | GitHub Pages из ветки `main` | Cloudflare, Vercel |
| Автоматизация | GitHub Actions, крон каждые 4 часа | внешнего планировщика |
| Проверки | jsdom, ставится локально | зависимостей в репозитории |

## Сторонних запросов со страницы — ноль

Открытая страница не ходит никуда, кроме своего же домена: ни CDN, ни
шрифтов, ни аналитики, ни счётчиков. Всё, что она грузит, лежит в этом же
репозитории.

Отсюда и решения, которые иначе выглядели бы странно: свой разбор markdown,
свои графики, свой словарь. Подключить готовую библиотеку с CDN нельзя, а
класть в репозиторий чужой минифицированный файл значит держать зависимость,
которую никто не читает и не обновляет.

## Где всё-таки есть внешний мир

**У сборщиков, а не у браузера.** Данные приезжают в репозиторий заранее, а
страница читает уже готовые JSON.

| Источник | Что даёт |
|---|---|
| Amazon SP-API | продажи, финансы, состояние аккаунта, купоны и дилы |
| Европейский центробанк | справочные курсы для перевода в евро |

## На какие возможности браузера опирается

ES-модули, `fetch`, `localStorage` и `sessionStorage`, WebCrypto
(`crypto.subtle`), `Intl` (числа, даты, список часовых поясов),
`ResizeObserver`, `matchMedia`, элемент `<dialog>`, SVG.

Всё это есть в любом браузере последних лет. Полифилов нет.

## Размер на 2026-08-19

18 модулей JavaScript (~5 200 строк), ~2 100 строк CSS, 8 файлов данных
(1,2 МБ). Проверки: `tools/` — монтаж разделов, сверка чисел, оболочка,
слой отметок.

## Что из этого обсуждалось и отклонено

- **React** — обсуждался, отклонён: появился бы шаг сборки.
- **Cloudflare, Vercel и прочий хостинг** — отклонены: всё держится на
  ресурсах GitHub.
- **Готовые библиотеки графиков и markdown** — не подходят: CDN недоступен,
  а вендоринг чужого кода в репозиторий нежелателен.

Поднимать эти вопросы заново не нужно.
