# Как добавить статью в вики

Статьи — обычные файлы markdown в репозитории. Кода трогать не нужно.

## Три шага

1. Положить файл `data/wiki/<имя>.<язык>.md`. Имя латиницей, через дефис.
2. Дописать запись в `data/wiki/index.json`.
3. Закоммитить. Через минуту статья на сайте.

Запись в указателе:

```json
{
 "slug": "имя-файла-без-языка",
 "tags": ["данные"],
 "updated": "2026-08-19",
 "langs": ["ru", "uk"],
 "title": { "ru": "…", "en": "…", "uk": "…" }
}
```

`langs` — языки, на которых статья **действительно** есть. Если текущего
языка в списке нет, статья откроется на русском с пометкой, что перевода
нет. Соврать в `langs` — значит получить пустую страницу вместо статьи.

## Что понимает разметка

Заголовки, абзацы, списки обычные и нумерованные, таблицы, цитаты, блоки
кода, горизонтальные линии, ссылки, `код в строке`, **жирный**, *курсив*.

Разбор — свой, в `assets/js/markdown.js`: стек без сборки, и подключить
готовую библиотеку с CDN нельзя. Дерево собирается через `createElement` и
`textContent`, поэтому разметка из статьи не может стать разметкой страницы.

Ссылка на другой раздел дашборда пишется как `#/имя-раздела`, например
[Продажи по неделям](#/weekly-sales).

## О чём писать стоит

О том, чего не видно из кода: принятые и **отклонённые** решения, расхождения
Amazon с документацией, обязательные шаги проверки. То, что выводится чтением
файлов, писать не нужно — оно устареет раньше, чем понадобится.
