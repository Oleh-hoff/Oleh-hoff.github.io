# Технічний стек

**Збирати нічого — коміт стає сайтом.** Це не наслідок лінощів, а ухвалена
вимога: у дашборда немає кроку збірки, і тому немає ні стану «зібралося
локально, але не в CI», ні застарілого артефакту, ні залежності, яка
зламається через рік.

## З чого зроблено

| Шар | Чим | Чого навмисне немає |
|---|---|---|
| Сторінки | статичний HTML, ES-модулі, CSS | бандлера, фреймворка, кроку збірки |
| Стилі | CSS custom properties, `data-theme` | препроцесора, Tailwind |
| Графіки | власний SVG-модуль `charts.js` | Chart.js, D3, Recharts |
| Markdown вікі | власний розбір `markdown.js` | marked, markdown-it |
| Мови | власний словник, ru / en / uk | i18next |
| Вхід | PBKDF2-SHA256, 150 000 ітерацій, WebCrypto | сервера, сесій, БД |
| Дані | статичні JSON у `data/`, читаються `fetch` | API, бекенду |
| Збирачі | Python 3.12, **лише стандартна бібліотека** | requests, boto3, pandas |
| Клієнт SP-API | власний, LWA-токен у заголовку | AWS SigV4, SDK Amazon |
| Хостинг | GitHub Pages з гілки `main` | Cloudflare, Vercel |
| Автоматизація | GitHub Actions, крон кожні 4 години | зовнішнього планувальника |
| Перевірки | jsdom, ставиться локально | залежностей у репозиторії |

## Сторонніх запитів зі сторінки — нуль

Відкрита сторінка не ходить нікуди, крім власного домену: ні CDN, ні шрифтів,
ні аналітики, ні лічильників. Усе, що вона вантажить, лежить у цьому ж
репозиторії.

Звідси й рішення, які інакше виглядали б дивно: власний розбір markdown,
власні графіки, власний словник. Підключити готову бібліотеку з CDN не можна,
а класти в репозиторій чужий мініфікований файл означає тримати залежність,
яку ніхто не читає і не оновлює.

## Де все ж є зовнішній світ

**У збирачів, а не в браузера.** Дані приїжджають у репозиторій заздалегідь,
а сторінка читає вже готові JSON.

| Джерело | Що дає |
|---|---|
| Amazon SP-API | продажі, фінанси, стан акаунта, купони й діли |
| Європейський центробанк | довідкові курси для переведення в євро |

## На які можливості браузера спирається

ES-модулі, `fetch`, `localStorage` і `sessionStorage`, WebCrypto
(`crypto.subtle`), `Intl` (числа, дати, список часових поясів),
`ResizeObserver`, `matchMedia`, елемент `<dialog>`, SVG.

Усе це є в будь-якому браузері останніх років. Поліфілів немає.

## Розмір на 2026-08-19

18 модулів JavaScript (~5 200 рядків), ~2 100 рядків CSS, 8 файлів даних
(1,2 МБ). Перевірки: `tools/` — монтаж розділів, звірка чисел, оболонка,
шар позначок.

## Що з цього обговорювалося і відхилено

- **React** — обговорювався, відхилений: з'явився б крок збірки.
- **Cloudflare, Vercel та інший хостинг** — відхилені: усе тримається на
  ресурсах GitHub.
- **Готові бібліотеки графіків і markdown** — не підходять: CDN недоступний,
  а вендорити чужий код у репозиторій небажано.

Порушувати ці питання заново не потрібно.
