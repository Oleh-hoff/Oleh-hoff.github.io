# Як додати статтю у вікі

Статті — звичайні файли markdown у репозиторії. Коду чіпати не потрібно.

## Три кроки

1. Покласти файл `data/wiki/<ім'я>.<мова>.md`. Ім'я латиницею, через дефіс.
2. Дописати запис у `data/wiki/index.json`.
3. Закомітити. За хвилину стаття на сайті.

Запис у покажчику:

```json
{
 "slug": "ім'я-файлу-без-мови",
 "tags": ["данные"],
 "updated": "2026-08-19",
 "langs": ["ru", "uk"],
 "title": { "ru": "…", "en": "…", "uk": "…" }
}
```

`langs` — мови, якими стаття **справді** існує. Якщо поточної мови в списку
немає, стаття відкриється російською з поміткою, що перекладу немає. Збрехати
в `langs` — означає отримати порожню сторінку замість статті.

## Що розуміє розмітка

Заголовки, абзаци, списки звичайні й нумеровані, таблиці, цитати, блоки коду,
горизонтальні лінії, посилання, `код у рядку`, **жирний**, *курсив*.

Розбір власний, у `assets/js/markdown.js`: стек без збірки, і підключити
готову бібліотеку з CDN не можна. Дерево збирається через `createElement` і
`textContent`, тому розмітка зі статті не може стати розміткою сторінки.

Посилання на інший розділ дашборда пишеться як `#/ім'я-розділу`, наприклад
[Продажі по тижнях](#/weekly-sales).

## Про що писати варто

Про те, чого не видно з коду: ухвалені та **відхилені** рішення, розходження
Amazon із документацією, обов'язкові кроки перевірки. Те, що виводиться
читанням файлів, писати не треба — воно застаріє раніше, ніж знадобиться.
