Генератор хэша пароля

Считает ту же производную, что проверяет форма входа: PBKDF2-SHA256, 150 000 итераций, соль привязана к сайту. Пароль никуда не отправляется — вычисление идёт в браузере.

Длинная фраза из нескольких слов надёжнее короткого набора символов. Хэш публичен — стойкость держится только на самом пароле.
Что делать с результатом
1. Скопируйте строку выше целиком.
2. Откройте assets/js/auth.js, найдите массив users.
3. Замените строку записи на скопированную.
4. Сохраните, закоммитьте и запушьте: git add -A && git commit -m "Смена пароля" && git push
5. Через 1–2 минуты GitHub Pages пересоберёт сайт, и новый пароль заработает.
